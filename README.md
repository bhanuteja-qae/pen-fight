# pen-fight

Turn-based two-player physics game: flick your pen across the table and knock your
opponent's pen off the edge. Godot 4.x / GDScript, targeting Android.

## Status

Pre-alpha. The playable skeleton is not yet committed to this repository — see
[`docs/RESEARCH.md` §1](docs/RESEARCH.md).
